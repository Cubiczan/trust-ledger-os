# Framework Benchmark Suite

Phase 2 scaffold for Trust Ledger OS.

## Contents

- `src/types.ts` - shared benchmark types.
- `src/frameworks.ts` - framework profiles and tradeoffs.
- `src/benchmark-cases.ts` - finance scenarios used in comparison runs.
- `src/scoring.ts` - scoring rubric and acceptance criteria.
- `src/scaffold.ts` - file map for the package boundary.
- `examples/framework-comparison.ts` - seed input for a later benchmark harness.

## Goal

Turn framework selection into a repeatable, finance-specific comparison rather than an ad hoc choice.
