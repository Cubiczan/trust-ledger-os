# Foundation Kit

Phase 1 scaffold for Trust Ledger OS.

## Contents

- `src/types.ts` - shared types for decisions, matrices, prompts, and scaffold files.
- `src/decision-tree.ts` - when-to-use-an-agent rules and sample finance use cases.
- `src/model-tool-matrix.ts` - starter model and tool selection rows.
- `src/prompts.ts` - reusable prompt skeletons for finance agent roles.
- `src/scaffold.ts` - file map and acceptance criteria for the phase.
- `examples/non-agentic-vs-agentic.ts` - concrete comparison example.

## Goal

Turn the roadmap into a reusable package boundary so the foundation work can be imported by future finance agent features.
