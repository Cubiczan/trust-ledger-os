# Research and Reasoning Kit

Phase 3 scaffold for Trust Ledger OS.

## Contents

- `src/types.ts` - shared types for the phase.
- `src/research-pipeline.ts` - planner, researcher, validator, and synthesizer stages.
- `src/reasoning-patterns.ts` - reusable reasoning paradigms for finance.
- `src/scaffold.ts` - package boundary and acceptance criteria.
- `examples/earnings-week.ts` - example input for a future notebook or harness.

## Goal

Package the research workflow and reasoning patterns so they can be reused across finance analysis, deep search, and decision support.
